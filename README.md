# 物联网智能灯杆 · 前端监控系统

基于 **Vue 3 + Vite** 构建的物联网智能灯杆前端监控管理系统，用于展示灯杆设备的实时数据、历史趋势、告警与检测信息。

> 本项目为 **3 人协作的全栈物联网项目**（嵌入式采集 + 后端服务 + 前端监控）的一部分，本人负责前端。前端对接**真实后端接口**（设备数据由嵌入式端采集上报），同时内置 Mock 数据开关，可脱离硬件独立演示与联调。

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 框架 | Vue 3（Composition API，`<script setup>`） |
| 构建工具 | Vite |
| UI 组件库 | Element Plus |
| 图表 | ECharts |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| HTTP 请求 | Axios |
| 时间处理 | Day.js |

## 功能页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/devices` | 设备列表 | 展示全部灯杆设备及其状态（首页默认） |
| `/device/:id` | 设备详情 | 单台设备的实时传感器数据 |
| `/history` | 历史查询 | 传感器历史数据曲线与数据列表，支持时间范围筛选与分页 |
| `/alerts` | 告警管理 | 设备告警信息展示 |
| `/detect` | 检测 | 设备检测相关信息 |

## 技术亮点

- **通用可视化图表组件封装**：抽象 `SensorTrendChart` 组件，用「字段配置」驱动多个子图与左/右双 Y 轴渲染，解决量级差异；新增传感器曲线或子图只需改组件内的字段配置、无需改渲染逻辑，做到配置驱动、易扩展。
- **图表数据细节处理**：按采集间隔自动识别数据断点并插入空值使曲线断开（避免误连线），大数据量下采用 `lttb` 采样降点、长跨度自适应 X 轴标签，并用 `ResizeObserver` 做容器级自适应。
- **真实接口对接 + Mock 双模式**：通过 `IS_MOCK` 开关在「联调真实后端」与「本地模拟数据」间切换；开发环境用 Vite 代理转发后端与摄像头服务，规避跨域。
- **统一请求层封装**：基于 Axios 实例 + 拦截器统一处理业务码（`code !== 200`）与错误，响应数据自动解包，页面层只关心业务数据。
- **历史查询完整交互闭环**：设备筛选 + 快捷时间范围（1h/24h/7d）与自定义时间段 + 分页，三者联动驱动表格与图表同步刷新。

## 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`

## 本地运行

```sh
# 安装依赖
npm install

# 启动开发服务器（热更新）
npm run dev

# 构建生产版本
npm run build

# 本地预览构建产物
npm run preview
```
